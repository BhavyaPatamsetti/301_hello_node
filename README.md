# Hello Node.js

A minimal Node.js exercise that defines and calls a function to print a greeting.

## What is included

- Entry point: `index.js`. No external runtime dependencies.

## Getting started

Install Node.js, then run:

```sh
node index.js
```

Expected output: `Hello Node.Js!`
